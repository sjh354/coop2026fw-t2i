# CSD golden set — 프론티어 모델 생성용 프롬프트 (임시 초안)

목적: 4개 스타일 프리셋(edu-flat-v2/observational/playful-soft/storybook-scene)의 CSD 참조셋을
**채점 대상 3개 후보 모델(lumina2/pixart-sigma/flux2-klein-4b-nf4)과 독립적으로** 재구성하기 위한
프론티어 모델(GPT-Image, Midjourney 등) 입력 프롬프트. 아래는 그대로 복붙해서 쓰는 완성형 프롬프트.

원칙 (bench/style-presets-v2.md "5. CSD ref_set 수집 기준" 그대로 적용):
- 피사체는 최대한 다양하게, 스타일은 균일하게 — CSD가 스타일만 순수 측정하도록.
- 피사체는 `configs/keywords/bench_v1.yaml`(벤치마크 채점용 40개 키워드)과 겹치지 않게 선정함.
- 화면 내 텍스트/워터마크 포함 이미지는 제외 (프롬프트에도 명시).
- 각 프리셋 20개 생성 → 실제로는 스타일이 가장 잘 맞는 15~25장만 골든셋으로 채택(과대생성 후 큐레이션).

생성 후 `scripts/validate_ref_set.py`로 pairwise CSD 일관성 검증(outlier는 재생성/교체) 절차는 그대로 유지.

## 사용 순서

1. 위 코드블록의 프롬프트를 한 줄씩 그대로 복붙해서 프론티어 모델에 입력해 이미지 생성.
2. 생성물 중 스타일이 가장 잘 맞는 15~25장만 골라 `refs/golden-set/<preset>/`에 저장

educational illustrations for K-12 classroom slides.

INPUT: a complete English content description already written for this
domain (objects, exact counts, spatial layout).

TASK: rewrite it into a clearer, more structured version for the image

OUTPUT: exactly one line of English text, no explanations, no quotes, no
line breaks.

- Never add photographic or rendering-style vocabulary: no
  "photorealistic", "cinematic", "8k", "4k", "ArtStation", "DSLR",
  "bokeh", "octane render", "ray tracing", "hyperrealistic", "photo".
- Keep the output describing a flat, simple illustration suitable for a
  classroom slide — do not push it toward realism.

  captions inside the image.

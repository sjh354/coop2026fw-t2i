CSD Golden Set 보강 전/후 비교 — lecture24

refs/lecture24/ 8개 카테고리에 이미 모여있던 후보 이미지(15~24장/카테고리)를 정식 검증해 scripts/score_csd_golden.py 다중참조 평균 채점(csd_golden)으로 전환했을 때, 기존 단일참조 채점(csd_target, 카테고리당 참조 1장)과 비교해 전반적으로 어떻게 달라지는지 탐색한 결과.

Executive Summary

  • golden set 검증 완료: lecture24 8개 카테고리 각각 15~24장(총 158장)을 scripts/validate_ref_set.py로 검증 — 8개 전부 status=validated, outlier 없음. README.md의 미완료 체크리스트 항목("CSD golden set 보강")을 이번에 완료.
  • 재채점 규모: 기존 csd_target(참조 1장) 채점이 있던 18개 run, 420장 이미지 전체를 새 csd_golden(참조 15~24장 평균)으로 재채점.
  • 상관관계는 강함: Pearson r=0.83, Spearman ρ=0.78 — 골든셋 보강 후에도 이미지 간 상대적 순위는 대체로 유지된다.
  • 절대값은 전반적으로 하락: 420장 중 334장(80%)에서 csd_golden < csd_target. 평균 하락폭 -0.107. 참조 1장과 우연히 잘 맞았던 값이 다수 이미지 평균과 비교하면서 낮아지는 방향.
  • 카테고리별로 방향과 크기가 다르다: Single-Character Cutout(-0.240)처럼 크게 떨어지는 카테고리가 있는 반면, Historical Figure Portrait(+0.046)는 오히려 오른다. 단순 스케일 이동이 아니다.
  • run(모델·조건) 간 순위는 대체로 안정적: TASK-F(qwen-image vs lightning), ideogram-4 스키마 비교 등 기존 결론에서 순위가 뒤집힌 사례는 없음. 값이 근접했던 쌍(v257/v258)에서만 미세한 순서 변화 관찰.
Limitation 카테고리별 delta의 방향이 왜 갈리는지(내부 self-similarity, 원 단일참조 이미지의 특이성 등)는 이번 탐색에서 원인을 확정하지 못했다. 상관 분석 결과 골든셋 내부 self-similarity(mean)만으로는 delta 크기를 설명하지 못했다 — 추가 조사가 필요한 열린 질문으로 남겨둔다.

1. 배경 및 방법

lecture24 벤치(교과서 이미지에서 VLM으로 역추출한 8카테고리 × 3소스 = 24개 완성 프롬프트)의 CSD 채점은 그동안 scripts/score_csd_target.py로, 카테고리당 참조 이미지 1장만 비교하는 provisional 방식이었다(README.md 체크리스트 미해결 항목). 그런데 refs/lecture24/<카테고리>/ 아래에 이미 카테고리당 15~24장의 후보 이미지가 로컬에 모여 있었으나, git에 커밋되지 않았고 (refs/가 .gitignore 대상), 채점 스크립트에도 연결돼 있지 않은 상태였다.

이번 작업은:

  1. 이 후보 이미지들을 서버 23(GPU, t2i-score env)으로 옮기고 scripts/validate_ref_set.py로 정식 검증.
  2. 검증된 golden set 평균 유사도로 채점하는 scripts/score_csd_golden.py를 새로 작성(기존 src/scoring.py의 _csd() 정의 — ref_set 평균 코사인 유사도 — 재사용).
  3. 기존 csd_target 채점이 있던 18개 run(420장)을 csd_golden으로 재채점.
  4. 이미지 단위로 두 값을 매칭해 전반적인 경향(상관관계, 델타, 카테고리·run별 방향)을 탐색.

3. 전체 비교: csd_target vs csd_golden

420장 이미지 전체에 대해 csd_target(x축)과 csd_golden(y축)을 산점도로 그리면, 대각선(y=x) 아래로 점들이 몰려 있어 golden set 기준이 대체로 더 낮게 나오는 경향이 뚜렷이 보인다. 그럼에도 점들이 대각선과 유사한 기울기로 흩어져 있어 순위 자체는 유지된다.

Inference 참조 이미지가 1장뿐이면 그 한 장과 우연히 잘 맞는 생성 이미지의 점수가 과대평가될 가능성이 있다. 15~24장 평균은 이런 우연한 일치를 희석시키므로, 전반적 하락은 "golden set이 더 엄격한 기준"이라는 해석과 부합한다. 다만 이는 추론이며, 이번 분석에서 직접 검증한 사실은 아니다.

6. 결론 및 다음 단계

  • 결론: golden set 보강은 lecture24 CSD 점수의 절대값을 전반적으로 낮추지만(평균 -0.107, 80% 이미지 하락), 상대적 비교(run 간 순위, 모델 간 순위)에는 큰 영향을 주지 않는다. 따라서 이미 csd_target으로 내린 상대적 결론들(TASK-F 속도 비교, ideogram-4 스키마 순위 등)은 재검토가 급하지 않다.
  • 다만 카테고리별 절대값 비교(예: 어떤 카테고리가 특히 스타일 정렬이 잘 안 되는지)는 방향이 카테고리마다 다르므로, csd_golden으로 다시 봐야 한다 — 특히 TASK-I처럼 카테고리를 그룹으로 묶어 해석하는 분석은 csd_target 기준 결론을 그대로 재사용하면 안 된다.
  • 다음 단계 후보 (사용자 확인 필요): (a) 이번 golden set 검증·재채점을 정식 채점 경로로 승격하고 bench/results.md의 기존 csd_target 언급을 csd_golden 기준으로 갱신할지, (b) 카테고리별 delta 방향이 갈리는 원인을 추가로 조사할지, (c) 보류했던 TASK-J(스타일 프리셋 LoRA 전환 임계값)로 복귀할지.
